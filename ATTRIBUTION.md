# Attribution & Inspiration

## Inspired by 9router

**Dissector was inspired by the [9router](https://github.com/decolua/9router) project created by [@decolua](https://github.com/decolua).**

9router introduced the core ideas that Dissector builds on:

- A self-hosted gateway that lets coding tools such as Claude Code, Codex, and OpenCode talk to many AI providers through a single OpenAI-compatible endpoint.
- Format translation between provider APIs (OpenAI ↔ Claude and others).
- Automatic fallback across subscription, cheap, and free providers so coding sessions keep running.
- Tool-output compression ("RTK" token saving) to reduce token usage.

This project began as a rebranded fork of that work and has since been extended with:

- A selectable hacker-themed interface (Matrix, Cyberpunk, Amber CRT, Spectrum).
- A menu-driven Windows launcher (`RUN_DISSECTOR.bat`).
- "Launch as App" actions that open configured CLI tools in their own windows.
